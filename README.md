# RAG-ассистент по сайту КФУ

## Цель проекта

Создать интеллектуального ассистента, который отвечает на вопросы по официальным материалам Казанского федерального университета и указывает ссылки на использованные страницы.

Ассистент использует только найденный контекст из базы знаний. Если подтверждённого ответа нет, он сообщает об этом, а не придумывает информацию.

## Первая версия проекта

На первом этапе область знаний ограничивается разделами сайта, связанными с поступлением:

- правила приёма;
- направления подготовки и образовательные программы;
- документы и сроки подачи;
- контакты приёмной комиссии;
- общежития для студентов.

После проверки качества область можно расширить на факультеты, учебный процесс и студенческие сервисы.

## Планируемая архитектура

```text
Вопрос пользователя
        ↓
Гибридный поиск: BM25 + векторный поиск
        ↓
LLM формирует ответ по найденным фрагментам
        ↓
Validator → Critic → Editor
        ↓
Ответ со ссылками на страницы КФУ
```

Мультиагентная оркестрация будет реализована самостоятельно, без LangChain и LangGraph.

## Технологический стек

- Python 3.10+;
- FastAPI и Uvicorn;
- PostgreSQL или SQLite на раннем этапе;
- Qdrant для векторного поиска;
- BM25 для лексического поиска;
- Sentence Transformers для embeddings;
- Ollama как основной локальный LLM-бэкенд;
- Pydantic Settings для конфигурации;
- pytest для тестирования;
- Docker Compose для запуска сервисов.

## Метрики качества

- релевантность ответа вопросу;
- фактическая точность;
- подтверждённость ответа найденными фрагментами;
- наличие и корректность ссылок;
- полнота ответа;
- доля ответов с выдуманными фактами;
- среднее время ответа.
