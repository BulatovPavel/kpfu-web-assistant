# Ассистент по сайту КФУ

**Цель проекта:** Создание ассистента по сайту КФУ, который будет осуществлять помощь при навигации по сайту и выдавать справочную информацию, указанную на сайте

**Обоснование:** Сайт КФУ довольно информативный и объемный по содержанию. Таким образом, текущей навигации на сайте может быть недостаточно для пользователей. Данный ассистент может помочь с этим, став дополнением к встроенной навигации
