# Отчёт по этапу 1: выбор темы и настройка окружения

## 1. Тема проекта

Разрабатывается RAG-ассистент по официальному сайту Казанского федерального университета.

Ассистент должен отвечать на вопросы пользователей по материалам КФУ, использовать найденный контекст из базы знаний и указывать ссылки на источники.

Если подтверждённого ответа нет, система должна сообщать об отсутствии информации, а не генерировать неподтверждённые факты.

## 2. Границы первой версии

На первом этапе область знаний ограничена информацией для абитуриентов:

- правила приёма;
- направления подготовки и образовательные программы;
- необходимые документы;
- сроки подачи документов;
- контакты приёмной комиссии;
- информация об общежитиях.

В дальнейшем область знаний можно расширить на факультеты, учебный процесс и студенческие сервисы.

## 3. Планируемая архитектура

```text
Вопрос пользователя
        ↓
Гибридный поиск: BM25 + векторный поиск
        ↓
Формирование ответа LLM по найденному контексту
        ↓
Validator → Critic → Editor
        ↓
Ответ со ссылками на страницы КФУ
```

Мультиагентная оркестрация будет реализована самостоятельно, без LangChain и LangGraph.

## 4. Выбранный стек

- Python 3.10+;
- Poetry для управления зависимостями и виртуальным окружением;
- FastAPI и Uvicorn для REST API;
- PostgreSQL или SQLite на раннем этапе;
- Qdrant для векторного поиска;
- BM25 для лексического поиска;
- Sentence Transformers для embeddings;
- Ollama как основной локальный LLM-бэкенд;
- Pydantic Settings для конфигурации;
- pytest для тестирования;
- Docker Compose для запуска сервисов.

## 6. Метрики качества

В следующих этапах будут оцениваться:

- релевантность ответа вопросу;
- фактическая точность;
- подтверждённость ответа найденными фрагментами;
- наличие и корректность ссылок;
- полнота ответа;
- доля ответов с выдуманными фактами;
- среднее время ответа.

## 7. Проверки

Конфигурация `pyproject.toml` проверена как корректный TOML-файл.

После установки Poetry необходимо выполнить:

```powershell
poetry --version
poetry check
poetry install
poetry run python --version
```
